# louis--gabor-web

Сайт магазина мужской обуви **Louis Gabor** (Ташкент) — MVP для показа клиенту.
Статический сайт на Next.js, без бэкенда и админки. Два языка: `/ru/` и `/uz/`.

## Идея подачи

Фото из канала сняты на полке магазина. Скрипт вырезает пару с фона и ставит её на единый «студийный» фон:
одинаковая ширина пары, общая линия пола, тень вдоль подошвы. Обувь при этом настоящая, ИИ её не перерисовывает.

- **Коллекция** — модели со студийными кадрами. Цвет переключается на месте: все кадры сняты с одного ракурса.
- **В движении** — модели, которые есть только в видео: короткие вертикальные ролики (шаг, посадка, подошва).
- **Детали** — кадры тиснения, монограммы и строчки из оригиналов 2048×2560.
- На странице одновременно играет только один ролик.

## Откуда данные

Артикулы, цены, размеры, цвета и отметка о подошве берутся из постов канала:

```bash
python3 scripts/parse-export.py
```

Скрипт пишет `src/data/export.json`. `npm run lint` дополнительно сверяет цены и артикулы с экспортом.
Тип модели (кроссовки, лоферы и т. д.) и привязка фото к цвету заданы в `src/data/catalog.ts` (`LOOKS`).

Если артикул публиковался несколько раз, берётся самый поздний пост.

## Медиа

```bash
pip install pillow numpy scipy "rembg[cpu]"
```

```bash
python3 scripts/build-media.py
```

Скрипт вырезает обувь (модель ~180 МБ скачивается один раз, вырезки кешируются в `.cache/`), делает студийные
кадры, мини-вырезки для переключателя цвета, кадры деталей, обложки «в руке» и ролики по 4–5 секунд без звука.
В CI он не запускается: результаты лежат в `public/media/`.

Чтобы добавить модель в «Коллекцию», нужно фото пары на той же полке с того же ракурса — допишите его в `STUDIO`.

## Где менять содержимое

| Что | Файл |
| --- | --- |
| Telegram, магазины | `src/data/site.ts` |
| Тип модели, фото по цветам, ролик | `src/data/catalog.ts` |
| Тексты интерфейса | `src/i18n/ru.ts`, `src/i18n/uz.ts` |
| Цвета и шрифт | `src/app/globals.css` |

Надпись LOUIS GABOR рядом с монограммой набрана шрифтом сайта (Manrope) — временная замена фирменного начертания.

## Публикация

Каждый push в `main` публикует сайт на GitHub Pages: `https://<владелец>.github.io/louis--gabor-web/`.
Один раз нужно включить: Settings → Pages → Source → «GitHub Actions».
